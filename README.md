## 🔗 Workflow Stacks

### 🎬 YouTube Creator Stack

1. **[ChatGPT](https://chatgpt.com)** — script, hooks and titles
2. **[ElevenLabs](https://elevenlabs.io)** — voiceover
3. **[Runway Gen-3](https://runwayml.com)** / **[Kling AI](https://klingai.com)** — make videos
4. **[Midjourney](https://www.midjourney.com)** — thumbnail art

### 💻 Indie Developer Stack

1. **[Cursor](https://cursor.com)** — code editor with AI
2. **[GitHub Copilot](https://github.com/features/copilot)** — auto-complete and ready code
3. **[Claude](https://claude.ai)** — check code, fix code and write docs

### ✍️ Content Writer Stack

1. **[Perplexity](https://www.perplexity.ai)** — research with sources
2. **[Claude](https://claude.ai)** — long writing
3. **[Notion AI](https://www.notion.com)** — put notes in order and make them neat

### 🎵 Short-Form Video Stack

1. **[Suno AI](https://suno.com)** — original music
2. **[Kling AI](https://klingai.com)** — video clips
3. **[ElevenLabs](https://elevenlabs.io)** — spoken words
